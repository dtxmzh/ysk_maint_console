# 维护操作台 (ysk_maint_console)

窗口化的本机运维操作台 —— 把日益庞大的 `ysk_maint_console.ps1` 维护菜单升级为 **WPF 窗口前端**：
左侧分组菜单树、右侧彩色终端回显、左上大号运行状态灯、底部进度条与操作按钮。

> 2026-11-20 起由「维护控制台」更名为「**维护操作台**」（避免与 Windows 组件混淆）。

## 界面构成

```
┌──────────────────────────────────────────────┐
│ [状态灯]        端口灯 8080/18200/9210/10808 │  ← 状态带
│ ┌───────────┬──────────────────────────────┐ │
│ │ 菜单树     │ 终端回显（可自由框选复制）    │ │
│ │ 双击行执行 │ 逐行同步落盘                 │ │
│ └───────────┴──────────────────────────────┘ │
│ [停止] [复制全部] [导出日志] [清屏] [进度▓▓▓] │
└──────────────────────────────────────────────┘
```

- **菜单树**：启动时经 `-DumpMenu` 从 ps1 实时装载，标签与危险级永不漂移；
  行内任意位置双击执行（自研双击判定），组行单击开合，⚠ 红色危险项弹强确认。
- **终端回显**：每次点击 = 单发 `pwsh -File … -Run <key>`，命令与输出实时流回；
  自由框选复制 / `复制全部` / `导出日志` 另存。
- **状态灯**：未运行·灰 / 运行中·黄闪（有告警·橙闪）/ 运行错误已停止·红 / 运行完毕·绿（有告警·橙）。
- **进度条**：运行中滑动 + 计时，终态定格（含用时与 exit code）。
- **强制终止**：`停止` 按钮 / 无选中时 `Ctrl+C` / `F6` = 终止本窗口发起的 pwsh 进程树（类似 Ctrl+C）。
- **同步日志**：`_data\ysk_maint_console.log` 逐行落盘（清屏不丢历史），单实例互斥保证日志源唯一。
- **3 分钟无输出看门狗**：只转橙提示，绝不自杀（长编译/下载属正常）。

## 安装与使用

1. 下载最新 Release 的 zip，解压 `ysk_maint_console.exe` 等全套文件到
   `D:\ProgramFiles\ysk_tools\ysk_maint_console\`。
2. 执行后端 `scripts\ysk_maint_console.ps1` 放到 `D:\ProgramFiles\ysk_tools\run\`（GUI 依赖它）。
3. 入口 bat 放 `D:\ProgramFiles\ysk_tools\`：直接双击 = 窗口版；`ysk_维护操作台.bat tty` = 原终端交互版。
4. 首次运行若火绒拦截，把 exe 目录加入信任区。

## 前后端协议（ps1 侧）

| 参数 | 作用 |
|---|---|
| `-DumpMenu` | 输出全菜单 JSON（含危险级 r / 影响行 w / 输入弹窗规格 p） |
| `-ListBak` | 输出 Strata 回滚库 JSON（u>2 的输入选择弹窗数据源） |
| `-Run <key> [-Arg <v>]` | 单发执行一个菜单项（stdin 关闭时中途输入走安全默认） |
| 退出码 | 0 正常 / 2 组项缺子项 / 1 失败 |

可选旁路配置：exe 同目录 `ysk_maint_console.ini`（`script=` / `pwsh=` 各一行，覆盖内置路径）。

## 构建

- 技术栈：.NET 10 · WPF · **纯代码无 XAML**（FrameworkElementFactory 构建控件模板）
- 编译：`cd src && dotnet publish -c Release -r win-x64 -o publish_win`
- 产物三件套：`ysk_maint_console.exe`（390K 目录版；自包含单文件亦可）
